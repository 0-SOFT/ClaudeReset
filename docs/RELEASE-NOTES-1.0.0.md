## ClaudeReset 1.0.0

Первый открытый выпуск. Программа для Windows 10 и 11 в два шага: сбросить всё, что Claude хранит на компьютере, и направить Claude в интернет только через ваш прокси.

**Скачать:** `ClaudeReset-1.0.0-setup.exe` — установщик (права администратора не нужны). Или `ClaudeReset-1.0.0-windows-x64.zip` — та же программа без установки.

### Что умеет

- **Сброс одной кнопкой.** Находит данные Claude Desktop и Claude Code, показывает, что и сколько места занимает, сам закрывает Claude, останавливает службу Cowork и сохраняет копии вашей работы, затем после подтверждения словом СТЕРЕТЬ стирает данные, сохранённые пароли Claude в Windows и вход на claude.ai в Chrome и Edge. Память Claude Code (файлы CLAUDE.md) можно сохранить.
- **Прокси одной кнопкой.** SOCKS5, HTTP или профиль VLESS+Reality: проверка связи, входа и адреса выхода, затем защита — Claude ходит в интернет только через прокси, остальные программы как обычно. Если прокси пропадёт, Claude останется без сети, а не выйдет напрямую.
- Понятное состояние защиты и одна кнопка-исправление для каждой проблемы.
- Светлая и тёмная тема, крупный масштаб экрана, управление с клавиатуры, руководство внутри окна.
- Удаление программы из «Приложений» Windows или из окна: сначала выключается защита.
- Режим для специалистов со всеми инструментами программы.

### Важно знать

- Установщик не подписан: Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
- Программа проверена автоматическими тестами (около 3600) на временных профилях; на компьютерах пользователей сброс и защита не проверялись.
- Что программа не делает: [ограничения](GUI-ACCEPTANCE.md).
