# С нуля: стереть всё, поставить прокси, войти в новый аккаунт

Для Windows 11. Всё делается в окне `ClaudeReset.cmd`, без команд. Окно проверено автоматическими тестами; живая проверка на реальном компьютере ещё не проводилась — если что-то пойдёт не так, запишите шаг и сделайте снимок экрана.

## 1. Получить или обновить программу

Командная строка (Пуск → «cmd»):

```
cd C:\CLAUDE-RESET
git checkout main
git pull origin main
```

Если папки `C:\CLAUDE-RESET` ещё нет:

```
cd C:\
git clone https://github.com/0-SOFT/CLAUDE-RESET.git
```

Нужен Python 3.12 с python.org (при установке отметьте «Add python.exe to PATH»). Подробнее — в [README](../README.md).

## 2. Открыть окно

Дважды щёлкните `ClaudeReset.cmd` в `C:\CLAUDE-RESET`. Первый раз программа 1–3 минуты готовит окружение Python, дальше окно открывается сразу.

## 3. Сброс — «Шаг 1 · Сброс»

1. Выберите, что сохранить: «Стереть всё, но оставить память» (ваши файлы CLAUDE.md вернутся) или «Стереть всё».
2. **На сайте Claude**, в браузере со старым аккаунтом: выйдите на всех устройствах и отзовите доступ Claude Code. Кнопки «Скопировать адрес» дают нужные ссылки. Поставьте отметку «Готово».
3. **Закройте** VS Code (сохраните файлы), Chrome и Edge. Claude Desktop программа закроет сама.
4. Нажмите **«Проверить и очистить»**. Прочитайте, что найдено, введите **СТЕРЕТЬ** и подтвердите.
5. Если программа пишет «Нужно сделать вам» — сделайте и нажмите «Проверить снова». Ничего не удаляется, пока все такие пункты не выполнены.
6. Прочитайте итог: стёрто ли всё в проверенных папках, вернулась ли память, сброшен ли ключ устройства Claude Desktop, вышли ли вы из claude.ai в браузерах. Если браузеры были открыты — закройте их и нажмите «Выйти из claude.ai в браузерах».

## 4. Прокси и защита — «Шаг 2 · Прокси и защита»

1. Выберите тип прокси: SOCKS5, HTTP или VLESS (файл профиля).
2. Введите адрес сервера, порт, логин и пароль. Если у вас есть прежний файл `socks5.json`, возьмите значения из него и введите в окно; файл переносите только вручную (флешка, локальная сеть), не через интернет-сервисы.
3. Если Claude Code работает у вас в VS Code и тоже должен ходить через прокси — включите флажок «Также защищать Claude Code внутри VS Code».
4. Нажмите **«Проверить и включить защиту»**. Подтвердите показанный адрес выхода, прочитайте, чего защита не закрывает, нажмите «Включить защиту». На запрос Windows нажмите **«Да»**.
5. Вверху страницы должно появиться «Защита включена».

## 5. Проверить и войти

1. Откройте Claude Desktop и войдите в **новый** аккаунт.
2. На странице «Помощь» → «Язык и часовой пояс» введите страну прокси (DE, TR или GB) и нажмите «Сравнить». Настройки Windows меняете вы сами — кнопки открывают нужный раздел.
3. Если включали защиту для VS Code: Ctrl+Shift+P → «Reload Window», затем /resume.

## Если что-то не получилось

- Страница «Помощь» → «Сохранить отчёт»: в отчёте нет паролей, адресов прокси и имени пользователя. Отправьте его вместе со снимком экрана.
- Вернуть Claude прямой выход в интернет: «Шаг 2 · Прокси и защита» → «Выключить защиту».
- Все инструменты программы — кнопка «Режим для специалистов» внизу меню. Прежние консольные `Wipe-Claude.cmd` и `Setup-Proxy.cmd` остаются для специалистов.
