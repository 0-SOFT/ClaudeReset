# Ограничения ClaudeReset

ClaudeReset 1.0.0. Здесь честно перечислено, что программа не делает и что в ней не проверено.

## Сброс

- Стираются папки Claude Desktop и Claude Code из фиксированного списка, сохранённые пароли Claude в Windows и, если вы выбрали, вход на claude.ai в Chrome и Edge (cookies и IndexedDB). «В проверенных папках ничего не осталось» означает именно эти места, а не весь компьютер.
- Кэш браузеров, Local Storage, Session Storage, Service Worker и Cache Storage сайта claude.ai не очищаются автоматически: удалите данные сайта в настройках браузера.
- Ваши проекты, переменные среды, WSL, Docker и SSH программа не трогает.
- Ключ устройства Claude Desktop сбрасывается только у проверенных версий Desktop. Для другой версии итог сброса прямо скажет, что ключ не сброшен.
- Программа не проверяет сервер: выход на всех устройствах и отзыв доступа на сайте Claude отмечаете вы сами.
- VS Code и браузеры программа не закрывает за вас: их закрываете вы, окно дождётся.
- Если службу Cowork нельзя остановить без прав администратора, сброс остановится и попросит сделать это вручную.

## Прокси и защита

- Защита касается только собственных соединений Claude Desktop, Claude Code в терминале и, если вы включили, Claude Code в VS Code. Остальные программы, общий браузер и сеть всего компьютера она не меняет.
- Если прокси не отвечает или адрес выхода изменился, Claude остаётся без сети: напрямую он не выйдет. Это сделано намеренно.
- Защита не закрывает: обращения через системную службу DNS Windows, гостевую машину Cowork, взаимодействие с другими программами и часть служебных процессов. Перед включением окно показывает этот список.
- Запасного прокси нет: при отказе прокси Claude ждёт, пока вы исправите или смените его.
- Для включения и выключения защиты Windows попросит разрешение (UAC).

## Что не проверено

- Программа проверена автоматическими тестами на временных профилях и подменённых системных вызовах. Сброс и включение защиты на реальных компьютерах пользователей не проверялись.
- Установщик не подписан: Windows покажет предупреждение «Windows защитила ваш компьютер».
- Передача Claude Desktop часового пояса, языка, сведений об оборудовании и имени пользователя Windows не измерялась.
- Интерфейс только на русском.
