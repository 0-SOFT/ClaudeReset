# ClaudeReset

[English](README.md) · **Русский**

Программа для Windows 10 и 11 в два шага: **сбросить** всё, что Claude хранит на компьютере, и **направить** Claude в интернет только через ваш прокси. После этого Claude видит вас как нового пользователя.

Бесплатно, с открытым исходным кодом. Сделано в [0-soft](https://0-soft.com).

Окно по умолчанию на русском. Кнопка **ENGLISH** в меню слева переключает его на английский (и **РУССКИЙ** — обратно); выбор запоминается. То же — в «Помощь» → «Оформление».

## Скачать и установить

1. Скачайте последний **`ClaudeReset-…-setup.exe`** со страницы [Releases](../../releases/latest).
2. Запустите его и нажмите **«Установить»**. Права администратора не нужны, Python и Git не нужны.
3. Windows может показать «Windows защитила ваш компьютер» — установщик не подписан. Нажмите «Подробнее» → «Выполнить в любом случае».
4. Откройте ClaudeReset ярлыком на рабочем столе или в меню «Пуск».

Без установки: скачайте `ClaudeReset-…-windows-x64.zip`, распакуйте и запустите `ClaudeReset.exe`.

## Как пользоваться

В окне два шага по порядку.

**Шаг 1 · Сброс.** Выберите, сохранить ли вашу память Claude Code (файлы CLAUDE.md), выйдите из старого аккаунта на сайте Claude и нажмите «Проверить и очистить». Программа покажет, что найдено, сама закроет Claude, сохранит копии ваших файлов и после подтверждения словом СТЕРЕТЬ сотрёт данные.

**Шаг 2 · Прокси и защита.** Введите адрес, порт, логин и пароль прокси (SOCKS5, HTTP или файл профиля VLESS) и нажмите «Проверить и включить защиту». Программа проверит прокси, покажет адрес выхода и после вашего согласия включит защиту: Claude будет ходить в интернет только через прокси, остальные программы — как обычно.

Затем откройте Claude и войдите под новым аккаунтом. Подробно — [руководство](docs/USER-GUIDE.md), оно же открывается в окне на странице «Помощь». Что программа не делает и что не проверено — [ограничения](docs/GUI-ACCEPTANCE.md).

## Удаление

«Параметры → Приложения → ClaudeReset → Удалить» или кнопка «Удалить ClaudeReset» на странице «Помощь». Программа сначала выключит защиту, если она включена.

## Для разработчиков

Нужен Python 3.12.

```
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
cd src
..\.venv\Scripts\python.exe -m pytest -q
```

Из исходников окно запускает `ClaudeReset.cmd`. Установщик и портативный архив собирает `.venv\Scripts\python.exe tools\build_bundle.py --out <пустая папка>`.

Устройство: `src/claude_reset/shell.py` — окно; `reset_flow.py` и `proxy_flow.py` — логика двух шагов; `brand.py` — фирменный стиль; `app.py` — режим для специалистов со всеми инструментами.
